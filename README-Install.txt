ProKrita — Install on another PC / Installer sur un autre PC

English
1. Copy ProKrita.zip to the laptop. Keep it zipped.
2. In desktop Krita, choose Tools > Scripts > Import Python Plugin from File
   and select ProKrita.zip. Accept the prompt to enable the plugin.
3. Restart Krita and open a canvas. If the Smudge button is missing, enable
   ProKrita in Settings > Configure Krita > Python Plugin Manager and restart.

To blend separate layers, show the shadows and highlights you want, then
choose ⋯ > Smudge visible layers on a new layer. Paint across their edge.
Only your strokes go on the transparent Smudge blend layer. Edits underneath remain visible in untouched areas. Tap Paint to return to your brush.

Français
1. Copiez ProKrita.zip sur le portable, sans le décompresser.
2. Dans Krita, ouvrez Outils > Scripts, puis choisissez la commande qui permet
   d’importer un module Python depuis un fichier. Sélectionnez ProKrita.zip
   et acceptez l’activation si Krita vous la propose.
3. Redémarrez Krita et ouvrez un dessin. Si le bouton Smudge manque, activez
   ProKrita dans Configuration > Configurer Krita > Gestionnaire de modules
   Python, puis redémarrez Krita.

Pour fondre les ombres et les lumières de plusieurs calques, affichez les
calques voulus et choisissez ⋯ > Smudge visible layers on a new layer.
Passez le pinceau sur leur jonction. Seuls vos coups de pinceau apparaissent sur le calque transparent Smudge blend. Les retouches des calques inférieurs restent visibles dans les zones intactes. Touchez Paint pour reprendre votre pinceau.
